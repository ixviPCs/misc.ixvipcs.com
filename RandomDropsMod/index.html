Random Drops Mod

Turn every block into a surprise! This mod randomizes all block drops—anything can drop anything, from items to blocks you’d never expect.

Not feeling the current drops? Just use /redrop to reshuffle them instantly and keep the chaos going! 🎲

Features:
  • Randomizes all block drops in your world.
  • Use /redrop anytime to reshuffle drops.
  • Lightweight and easy to install.
Notes:
  • Server side mod (only necessary on client if playing singleplayer).
  • Self-contained mod, only Fabric API needed.
Singleplayer (Client Side):
  • Download the mod version you want to play.
  • Download the same version of Fabric API.
  • Put both in your Minecraft mods folder. If it doesn’t exist, make one named exactly mods.
  • The usual path for the mods folder is:
    Windows: C:\Users\<YourUsername>\AppData\Roaming\.minecraft\mods
    Mac: /Users/<YourUsername>/Library/Application Support/minecraft/mods
    Linux: /home/<YourUsername>/.minecraft/mods
  • Start Minecraft with a Fabric client that matches your mod version.
  • If you don’t already have it, download the client installer here.
  • Have fun causing chaos in your world!
Server Side (Multiplayer):
  • Put the mod and Fabric API in the server’s mods folder.
  • Start the server—players don’t need any mods to see the random drops.
  • Server operators can use /redrop to reshuffle drops anytime.
